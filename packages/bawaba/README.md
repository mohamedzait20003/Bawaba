# bawaba

One TypeScript payments API for Paymob, Kashier, Fawry, Geidea, PayTabs, Amazon Payment Services and Tap Payments: payments, refunds and verified webhooks across Egypt and the Gulf.

> **Unofficial.** Not affiliated with Paymob, Kashier, Fawry, Geidea, PayTabs, Amazon Payment Services or Tap Payments.

**Status: pre-alpha, not usable.** This package is a scaffold placeholder.

## Entry points

| Entry | Purpose |
|---|---|
| `bawaba` | The `Bawaba` facade |
| `bawaba/paymob` | The Paymob gateway factory |
| `bawaba/kashier` | The Kashier gateway factory |
| `bawaba/fawry` | The Fawry gateway factory |
| `bawaba/geidea` | The Geidea gateway factory |
| `bawaba/paytabs` | The PayTabs gateway factory |
| `bawaba/payfort` | The Amazon Payment Services gateway factory |
| `bawaba/tap` | The Tap Payments gateway factory |

An app bundles only the gateway subpaths it imports.
